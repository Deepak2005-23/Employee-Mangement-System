# Employee Management System - React Vite Frontend

This project was built with React, Vite, Axios, and Bootstrap 5 to connect to the Spring Boot backend (`emc-backend`).

## Features
- List Employees (`/employees`)
- Add New Employee (`/add-employee`)
- Update Employee (`/update-employee/:id` or `/edit-employee/:id`)
- Delete Employee
- Form validations
- About Page (`/about`)

## Backend Connection
- Spring Boot REST API Endpoint: `http://localhost:8080/api/employees`

## Running the Application
```bash
npm install
npm run dev
```
The application runs by default on `http://localhost:3000`.
